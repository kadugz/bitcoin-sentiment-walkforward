# -bitcoin-sentiment-walkforward
LSTM com dados numéricos de preço/volume do BTC-USD vs. o mesmo modelo com sentimento de notícias (FinBERT), avaliados com split walk-forward, baselines honestos (persistência/ARIMA), teste estatístico pareado e simulação de trading com custos. Resultado majoritariamente nulo, discutido à luz da Hipótese de Mercado Eficiente.
